# predmaint

Et system for prediktivt vedlikehold på jernbanen ved hjelp av akustikk.

## Planer og struktur

- [Hovedplan](plan-predmaint.md): langsiktig iPhone-/Azure-løsning og faglig vurdering.
- [Frontend](front-end/README.md): native iPhone-app i Swift/SwiftUI.
- [Plan for første iPhone-app](front-end/plan-iphone.md): lokale lydopptak og avspilling, med nybegynnerveiledning.
- [Plan for repo-struktur og første lokale iPhone-app](front-end/plan-repo-struktur-og-iphone.md): samlet, godkjent planleggingsgrunnlag for dokumentasjonsleveransen.
- [Backend](back-end/README.md): senere Python/uv-backend i Azure.

Første etappe er en lokal læringsapp uten Azure, innlogging eller opplasting. Repoet inneholder foreløpig planer og dokumentasjon, ikke implementert app eller backend. Planrevisjoner versjoneres med Git.
